# Contributing

Engineering Intelligence Platform is currently in its early design phase.

## Principles

- Grow the repository only when a vertical slice demonstrates a need.
- Keep product, repository, and instance-specific decisions separate.
- Capture significant architecture decisions as ADRs.
- Keep changes small, focused, and reviewable.

## Development workflow

1. Create a branch from `main`.
2. Install the tooling with `npm install`.
3. Make one focused change.
4. Run `npm run check`.
5. Use a [Conventional Commit](https://www.conventionalcommits.org/) message.
6. Open a pull request using the repository template.

By contributing, you agree that your contribution is governed by the
repository's license.
